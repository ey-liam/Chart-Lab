Arquitectura de Chart-Lab y Reconocimientos
Inspirado en EFHIII / midi-ch & uwuHero

Chart-Lab es una reimaginación completa desde cero, diseñada para producción profesional sin errores. Agradecemos a Saffron Haas (@EFHIII) por crear el concepto original de conversión MIDI-CH y a la comunidad de uwuHero por popularizar la simulación de ritmo en el navegador.

Ecosistema Multi-Lenguaje de Chart-Lab:
  • Web Studio (HTML / CSS / JS): Interfaz reactiva oscura con canvas highway 3D, reproductor de audio stems, silabificador fonético y empaquetador ZIP cliente.
  • C# & ShaderLab (Unity / Desktop): Modelos de datos para Unity, linter de notas y shaders HLSL para carreteras curvas y gemas cristalinas con Star Power.
  • Python (CLI & Validator): Kit de herramientas por línea de comandos con analizador binario de MIDI y auditor de colisión de sustains.
  • Java Core (Cross-Platform): Motor portable para procesamiento de secuencias MIDI y renderizado por lotes con Maven.
